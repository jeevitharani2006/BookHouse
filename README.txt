BOOK HOUSE PROJECT

1. Extract this ZIP.
2. Open the Book_House_Project folder in VS Code.
3. Open index.html with Live Server, or double-click it to open in Chrome.
4. Use the navigation bar to open book.html, search.html and details.html.

Keep all files in the same folder. Internet is needed for Bootstrap and Open Library book covers. Prices and availability are sample data, not live inventory. The enquiry form validates in the browser only; it does not send messages, save to a database or upload files. Purchases happen at the physical bookstore; there is no cart, checkout, payment or delivery.
